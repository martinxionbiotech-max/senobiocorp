製品紹介

このキットにより、正確な 分子的性決定 などのサンプルを使用している。 羽毛、血液、組織, 特に、目視による雌雄識別が信頼できないか不可能なオウムの種については。.

アン 内因性内部参照 の両方をモニターするために、アッセイに組み込まれている。 核酸抽出とPCR増幅, 信頼性と再現性の高い結果を保証する。.

本製品は、以下を目的としている。 研究用のみ.

実験手順

1.サンプルの準備

（サンプル準備エリア）

1.1 サンプル要件

フェザー

  • 集める 少なくとも5枚の羽 胸部、腹部、脚部から

  • フェザーシャフトを含むこと

  • 自然に抜け落ちた羽毛は使用しないこと

血液

  • 用途 EDTA 抗凝固剤として

  • ヘパリンを使用しない

  • 保管条件

    • 2-8 °Cまで 7日

    • -20℃まで 3ヶ月

  • 凍結融解の繰り返しを避ける

組織

  • 新鮮な筋肉または臓器組織

  • 皮膚、腱、筋膜を避ける

  • サンプル量： ≤ 100 mg

  • を使用してホモジナイズする。 200-500 µL 滅菌水

1.2 核酸抽出

を使用して核酸を抽出する。 動物ゲノムDNA迅速抽出キット（PCR分析用）
(部品番号DP202、Three Lions Biotech社）。 またはその他の有効な抽出方法。.

  • 抽出した核酸は氷上に保存する

  • 抽出後の保管

    • 4℃まで 7日

    • -20℃まで 6ヶ月

2.反応系の調製

(サンプル追加エリア）

2.1 試薬の調製

  • 準備する n + 2 反応チューブ (n = サンプル数)

    • ポジティブ・コントロールとネガティブ・コントロールを1つずつ含む

  • 試薬を室温で完全に解凍する

  • 短時間の遠心分離 (10 s)を氷で冷やしておく

2.2 反応のセットアップ

  • 追加 2 µL のそれぞれを反応液に加える：

    • 陰性コントロール

    • サンプル核酸

    • CWポジティブコントロール

  • 最終反応量： 25 µL

  • 十分に混合し、短時間遠心分離し、増幅に進む。

3.PCR増幅

(増幅・分析エリア）

熱サイクル条件

  • プレ変性： 95 °C、3分間

  • 35サイクル：

    • 変性： 95 °C、10秒

    • アニーリング／エクステンション： 58℃、30秒

  • での蛍光取得 58 °C

蛍光チャンネル

  • FAM:CHD-W遺伝子

  • VIC / HEX:内因性参照遺伝子

ABIリアルタイムPCR装置では、ROXキャリブレーション色素が必要な場合があります。.

結果の解釈

1.妥当性の基準

  • ポジティブコントロール：

    • FAMおよびVIC/HEXの両チャンネルでCt < 28

    • 典型的なS字型増幅曲線

  • ネガティブコントロール：

    • CtなしまたはCt≧35

    • S字カーブなし

無効な場合は、実験を繰り返すか、テクニカルサポートに連絡する。.

2.内部制御（VIC/HEXチャンネル）

  • Ct≦30、S字カーブを描く
    → 抽出と増幅は有効

  • Ctなし、または30＜Ct≦35
    → 抽出不良またはPCR阻害の可能性
    → 再抽出と再検査を推奨

3.CHD-W遺伝子判定（FAMチャンネル）

  • Ct ≤ 30, S字型曲線、Ct差<5
    → CHD-W 陽性 → 女性

  • Ct≦30、Ct差≧5, あるいは 30 < Ct < 32
    → 疑わしい結果、再検査を推奨

  • Ctなし、またはCt≧32でS字状曲線なし
    → CHD-W 陰性 → 男性

よくある質問（FAQ）

1.このオウム性核酸検査キットは何に使うのですか？

このキットは以下の用途に使用される。 オウムの分子的性決定 保存された CHD-W遺伝子 リアルタイムPCR法を用いる。目視や形態学的な雌雄同定が信頼できないオウム種に適している。.

2.このキットにはどのような種類の検体が使用できますか。

このキットは、以下のような複数のサンプルタイプをサポートしている：

  • フェザー（フェザーシャフト付き）

  • EDTAで処理した全血

  • 新鮮な筋肉または臓器組織

3.自然に抜け落ちた羽毛を検査に使うことはできますか？

自然に抜け落ちた羽毛は、DNAが不十分であったり、劣化していたりすることが多く、検査結果の精度に影響を及ぼす可能性があるため、お勧めできません。.

4.どのような抽出方法を用いるべきか？

を使用することをお勧めします。 動物ゲノムDNA迅速抽出キット（PCR分析用） (Part No. DP202, Three Lions Biotech)、またはPCRアプリケーションに適した他の有効なDNA抽出方法。.

5.内部参照遺伝子は何を示すのか？

内因性内部参照遺伝子（VIC/HEXチャンネル）は、以下のモニターに使用される。 DNA抽出品質とPCR増幅効率. .有効な内部統制の結果は、検査プロセスが信頼できるものであることを確認する。.

6.このキットを使って、オスとメスのインコはどのように見分けるのですか？

  • の検出 CHD-W遺伝子（陽性） は 女性 オウムだ。.

  • 有効な内部コントロールでCHD-Wが増幅されないことは、以下のことを示している。 男性 オウムだ。.

7.結果が疑わしい場合はどうすればよいですか？

もし結果が疑わしい範囲（例えば、カットオフ付近のCt値や異常なCt差）に入った場合は、次のことをお勧めします：

  • エアロゾル汚染の可能性を排除する

  • 核酸の再抽出

  • PCR検査を繰り返す

8.陰性であれば必ずオスのインコですか？

必ずしもそうとは限りません。サンプルの質が悪い、DNA濃度が低い、PCR阻害物質がある、まれに遺伝子変異がある、などの理由で偽陰性の結果が出ることがあります。適切なサンプリングと抽出が重要です。.

9.このキットはどのリアルタイムPCR装置に対応していますか？

キットはほとんどの標準的なリアルタイムPCR装置と互換性がある。使用時 ABIシリーズ, ROXキャリブレーション染料が必要な場合がある。.

10.このキットは臨床用または診断用に適していますか？

いいえ。 研究用のみ そして 臨床診断または獣医学的診断を目的としたものではありません。.
